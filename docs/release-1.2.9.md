# ReviewOps 1.2.9

- **Parallel project reviews:** Work on reviews across multiple projects in separate windows. New requests for the same project return to its existing window.
- **Reviews from external tools:** Use the shared ReviewOps skill to send review requests from Codex, Claude Code, Hermes, and other tools that can run commands.
- **Independent workspaces:** Keep drafts, browser sessions, and terminals separate while working across projects.
- **Reliable requests:** Retry interrupted requests, check their status, and reopen saved reviews without creating duplicates.
