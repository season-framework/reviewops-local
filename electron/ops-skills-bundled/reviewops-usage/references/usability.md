# Usability inspection format

For each workflow record the environment, target and actual operations. Use Item / Operation / Expected behavior / Actual result with Pass, Fail, Partial or Not run. Describe concrete overlapping text, clipped controls, redundant navigation, unclear status or lost input rather than unsupported usability scores.

Preserve whole-window context, readable labels and state. Annotate only a copy and explain each number. Different versions, fixtures or sessions must be disclosed instead of presented as a continuous before/after operation. Do not reuse example images as newly captured evidence.
