# Screen and task flow

Home shows projects and reviews. Groups organize projects. Project screens contain reviews, dashboards, files and settings. Ops contains management conversations and persistent goals. Settings contains application preferences, remote management, skill management and backup/restore.

Read a review and its comments before responding. Review comments and agent runs are separate records. Read goals and schedules before changing status. Use exact identifiers returned by the selected app. A remote project connection is not a local folder; preserve its connection and working path. Do not silently switch between local and SSH targets.
